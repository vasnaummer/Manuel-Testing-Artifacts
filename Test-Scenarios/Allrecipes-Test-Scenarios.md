# Test Scenarios for Allrecipes Website

## Application Under Test
**Website:** Allrecipes.com  
**Testing Type:** Functional Testing  
**Tested By:** Vasna Ummer
**Date:** February 2025

---

## Test Scenarios

### 1. User Registration
- Verify user can create a new account with valid email
- Verify user cannot register with already existing email
- Verify password strength validation works correctly

### 2. Recipe Search Functionality
- Verify user can search recipes by name
- Verify user can filter recipes by cuisine type
- Verify search results display relevant recipes

### 3. Recipe Details Page
- Verify recipe ingredients are displayed correctly
- Verify cooking instructions are in proper order
- Verify user can view recipe ratings and reviews

### 4. User Login
- Verify user can login with valid credentials
- Verify appropriate error message for invalid credentials
- Verify "Forgot Password" functionality works

### 5. Add Recipe to Favorites
- Verify logged-in user can save recipes to favorites
- Verify user can view all saved favorite recipes
- Verify user can remove recipes from favorites

### 6. Recipe Rating and Review
- Verify user can rate a recipe (1-5 stars)
- Verify user can write and submit a review
- Verify review appears on recipe page after submission

### 7. Navigation and UI
- Verify all menu links work correctly
- Verify website is responsive on mobile devices
- Verify images load properly on all pages
